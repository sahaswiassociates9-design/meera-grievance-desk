Residents' open-issues register

Meera Shantivanam

A public, volunteer-run repository of open issues. Log an issue with your mobile number; close it yourself once it's fixed.
Please note: this is a voluntarily built, resident-run grievance portal. It is not operated by, affiliated with, or endorsed by Meera maintenance or anyone associated with Meera, Kanha, Madhuvanam or Kaivalyadham. Nobody monitors this register or works on the issues; it only records what residents report so that everyone can see what is open.
Before you log here: please report the issue to Meera Management first through their regular channels. Use this portal only if the issue stays unresolved for a long time. This is just a repository of open issues so residents can see what is pending; no active action is taken on anything logged here.
How it works: anyone with this link can log an issue. Your mobile number is mandatory and is never shown in full on the board (only as 98XXXXXX21). Only the ticket number together with the same mobile number can close a ticket. Each number can log up to 5 tickets a day.
